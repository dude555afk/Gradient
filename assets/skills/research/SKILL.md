# Research skill

1. Prefer official documentation.
2. Search GitHub issues when the behavior looks version-specific.
3. Open the actual source or docs, not only search snippets.
4. Cross-check claims that affect APIs, dependencies, migrations, or security.
5. Return source URLs with the conclusion.
6. Keep fetched text scoped to what the coding task needs.
