# GitHub skill

1. Inspect repository context before editing.
2. Never silently write to the default branch.
3. Create or use a task branch for mutations.
4. Read the current file SHA before replacing remote content.
5. Prefer minimal patches.
6. Show the user a diff before commit or push.
7. Verify changed files after mutation.
8. Keep issue, PR, and commit references in the task record.
